# Amazon India Sales Dashboard 📊

## Project Overview
This project focuses on analyzing Amazon India sales data using Microsoft Excel. The dashboard provides an overview of sales performance, profit, product categories, order status, payment methods, fulfillment, and state-wise sales.

The main aim of this project is to understand business performance through data analysis and visual representation.

## Dataset Information
- **Dataset:** Amazon India Sales Data
- **Records:** 10,000
- **Tool Used:** Microsoft Excel
- **Data Format:** Excel (.xlsx)
- ## dataset used
-    **https://docs.google.com/spreadsheets/d/1QyQtJgrxTKSlJv2A7-9Kz3IXXlo4g9uB/edit?gid=970134351#gid=970134351**

## Project Objectives
1. Analyze overall sales and profit performance.
2. Understand sales across different product categories.
3. Identify top-performing products.
4. Analyze order status, including completed, cancelled, and returned orders.
5. Examine customer payment methods.
6. Compare fulfillment methods.
7. Analyze sales performance across different states.

## Dashboard Features
- Key Performance Indicators (KPIs)
- Sales and profit analysis
